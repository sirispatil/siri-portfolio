# Siri Patil – Personal Portfolio Website

## About the Project
This is my personal portfolio website developed as part of my academic project. It presents my educational background, technical skills, certifications, projects, hobbies, and contact information in a structured and user-friendly format.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery

## Website Sections
- **Home:** Introduction and personal profile.
- **Resume:** Educational qualifications, technical skills, and certifications.
- **Bio-data:** Personal details, languages, and hobbies.
- **Projects:** Academic projects and their descriptions.
- **Contact:** Contact information and contact form.

## Features
- Responsive website design.
- Easy navigation between pages.
- Interactive elements using JavaScript and jQuery.
- Resume printing option.
- Contact through email.

## Cloud Platform
The website is hosted using **GitHub Pages**, a static website hosting service.
